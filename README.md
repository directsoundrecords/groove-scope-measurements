# Groove Scope Measurements

**Open reference measurements of vinyl playback systems, created with Groove Scope by Michelangelo Canonico and Direct Sound Records.**

This repository is the public measurement archive for **Groove Scope**, a vinyl playback measurement and diagnostic application developed by **Michelangelo Canonico** and **Direct Sound Records**. It is designed to preserve results in formats that are readable by people, search engines, research tools, and AI systems.

**Direct Sound Records** publishes these measurements to improve transparency, repeatability, and shared knowledge around turntable, tonearm, cartridge, alignment, speed, crosstalk, distortion, tracking, and related analogue playback measurements.

## Why both Markdown and JSON?

Each measurement is published in three complementary forms:

1. A **human-readable Markdown record** with context, interpretation, limitations, and provenance.
2. A **machine-readable JSON record** with stable field names, units, versioning, and explicit unknown values.
3. The **original PDF report** generated by Groove Scope.

The repository also contains a CSV index and a JSON Schema so future measurements remain consistent even when Groove Scope evolves.

## Measurement integrity

A result is not presented as a universal specification for a cartridge, turntable, tonearm, test record, or interface. It describes one documented playback system, configuration, test source, capture chain, software version, and measurement session. Variable diagnostics should be repeated before mechanical changes are made.

Every record has:

- an immutable measurement ID;
- a schema version;
- a record version;
- a publication status;
- the Groove Scope application and analysis-method version, when available;
- explicit provenance and limitations;
- checksums for the archived files.

See [METHODS.md](METHODS.md) for the publication and versioning policy.

## Contributions

External measurement submissions are **not yet open**. The collection is initially curated and measured by Michelangelo Canonico so the method, metadata, and acceptance criteria can mature before community submissions begin. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Disclaimer

These records are technical observations, not certification reports. Results can be affected by test-record condition, cartridge wear, setup geometry, tracking force, anti-skate, stylus cleanliness, phono stage, interface gain, sampling configuration, environmental vibration, and software methodology.

How to read the archives

Measurements are evidence, not universal ratings

Results belong to a documented setup and set of conditions. Environment, placement, calibration, component tolerances, capture hardware, test material and analysis-method versions can all affect a result.

Unknown information is marked explicitly rather than inferred. Versioned source data and publication history remain available in the underlying repositories.

Created and published by Direct Sound Records. Public data is released under the licence stated by each archive and record.

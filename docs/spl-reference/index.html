Privacy boundary

Only reviewed public information is shown

Exact coordinates, project names and original photograph metadata are not published. Location can be withheld entirely; when included, the public catalogue uses city and country rather than precise GPS position.

Interpretation

Context remains part of the result

These are measurements of particular environments and sessions. Microphone path, calibration status, placement, duration and local conditions affect how a result should be compared or reused.

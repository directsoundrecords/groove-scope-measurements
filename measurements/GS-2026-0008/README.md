# GS-2026-0008 — Ortofon 2M Bronze — Rega P3 / Audio Research SP20 / EVO4 — 1 kHz Reference Check

**Measured by Michelangelo Canonico for Direct Sound Records using Groove Scope.**

The Ortofon 2M Bronze delivers strong 1 kHz separation in this Rega P3 / Audio Research SP20 / EVO4 capture: 32.8 dB on average, with +0.53 dB channel balance. Playback averaged 33.34 RPM (+0.01%) with 0.027% DIN-shaped wow and flutter. THD was 0.98% left and 1.13% right; repeat the right-channel third-harmonic check before changing setup.

## Review context

At 1 kHz, Ortofon lists 26 dB channel separation and 1 dB channel balance for the 2M Bronze. Here, separation reaches 33.2 dB L→R and 32.4 dB R→L, while the 0.53 dB balance magnitude is inside that listed figure. These are encouraging in-system results; differences in test record, loading and measurement conditions prevent treating them as a cartridge-only certification. [Manufacturer specifications](https://ortofon.com/products/2m-bronze), consulted 2 October 2026.

Playback speed and distortion describe the complete captured chain. Repeat the right-channel third-harmonic check before changing setup; no listening impressions are inferred from these measurements.

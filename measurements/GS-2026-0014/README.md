# GS-2026-0014 — Charisma Audio MC-1 Alpha — 1 kHz Reference Check

**Measured by Michelangelo Canonico for Direct Sound Records using Groove Scope Studio.**

The SME Model 12 MkII averaged **33.32 RPM under stylus load**, just 0.04% below nominal, with **0.038% DIN-shaped wow and flutter**. With the Series V arm and Charisma Audio MC-1 Alpha fitted, both channels measured below 1% THD. The stereo measurements leave a clear question for a repeat session. The right channel leaked more strongly into the left, with a 5.57 dB gap between the two directions.

## Channel separation and follow-up

The measured crosstalk was −24.8 dB with the left channel driven and −19.2 dB with the right driven. The left channel’s output was separately measured 1.28 dB above the right. The report calls for checking routing and gain and repeating the capture. If the directional gap persists, it recommends the General Reference Level and 1 kHz channel suite in Groove Scope Studio with the matching test records.

The measurer flagged the condition of this particular cartridge sample as a question for follow-up. Repeating the measurement and comparing it with another sample could help clarify the separation and crosstalk results.

## Rotation Fingerprints

The contribution of the test record and the cause of the recurring speed pattern were not established.
